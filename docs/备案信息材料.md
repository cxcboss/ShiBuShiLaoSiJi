## 三、关于「是否需要工信部备案」——先读这段（重要）

> ⚠️ 纠正：之前材料里写的 `beian.huawei.com` 是**错误/不存在的域名**（权威 DNS 返回 NXDOMAIN，本机连不上是因为代理对不存在域名伪造了 fake-ip，并非被墙）。真正的备案平台不是这个名字。

华为侧规则（《APP核准（APP备案）指引》）：上架时在 AGC 备案区块有一个 **「您的APP为单机APP」** 选项。

- **本应用「老司机」= 纯本地单机，无自建服务器**（仅地图瓦片请求华为 Map Kit，无数据上传），符合「单机APP」定义。
- 走「单机APP」声明 → 通常**不需要**去工信部办 APP 备案号，AGC 备案区块无需填证件号即可提交。
- 第三方口径（阿里云社区/知乎等转述，非华为官方明文）：纯不联网、无接入商的单机 APP 无合法接入商、无法也无需备案。
- **不确定项**：华为官方只提供「单机APP」选项、并未公开声明监管豁免；工信部「未备案不得分发」是硬约束。最终以目标省份管局 + 华为审核实际反馈为准。

### 若审核要求必须备案（备用路径）
工信部 APP 备案在**接入商**办，不在华为 consumer 侧：
- 华为云备案中心（需你有大陆华为云可备案资源/授权码）：https://beian.huaweicloud.com
- 工信部备案系统（查询/短信核验）：https://beian.miit.gov.cn
- HarmonyOS 备案还需**应用公钥 / 发布证书 MD5 指纹**（从 .cer/.p12 提取，调试证书不可用），参见《HarmonyOS 备案公钥和签名获取指导(API12+)》。

### 首选动作
1. 回到 AGC 版本表单，确认「APP类型 = 单机APP」已选中。
2. 直接尝试 **保存 → 提交审核**：若系统因缺备案号报错，再考虑走工信部备案。
3. 「联系方式」区块（手机验证码 + 邮箱 + 姓名）仍需本人提供。
